### Language specification: the rules the bug rulings found missing (2026-10-29)

The 14 spec gaps the bug rulings listed are closed. Rules that state what the compiler already does
were written: PASS-12 (an accepted program is compiled; partial, bug 054), PASS-13 (every consumer
gives the checked Core behaviour), ARITH-7 (a float literal is correctly rounded), FFI-6 (a compiler
intrinsic is not a foreign binding), MEM-7 (a raw pointer to a live local denotes that local), MOD-8
(a generated call is bound by identity), MOD-9 (an import binds the declaration it names) and TYPE-9@2
(the type-argument count); a non-`mut` array element write was already OWN-10@2's. The four gaps whose
rule would choose behaviour became owner questions: OD43 (how a type position resolves a name), OD44
(two packages with one module name), OD45 (capability-variable inference) and OD46 (generic
type-argument inference). The affected bug records cite the new rules.
