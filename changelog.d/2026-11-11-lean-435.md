### Lean 4.35.0 and external checker toolchains

Concrete now uses Lean 4.35.0 throughout its active build, Nix release archives and CI.
The pinned lean-compiler-backend sources build unchanged as a dependency under 4.35.0;
that upstream revision's standalone declaration remains 4.34.1. No proof or definition
changed. The axiom inventory gained twelve compiler-generated Boolean-reflection helpers
for existing Surface0 decidability instances, each with an empty axiom set.

External Lean tools are checked against their revision's declared toolchain on every run,
including cache hits, and built with explicit elan dispatch. The exporter is pinned to
upstream v4.35.0 and must match Concrete. Elan installations are isolated under the
external cache before the project build too, so Nix's Linux patching cannot modify shared
user toolchains. Ambient ELAN_TOOLCHAIN and LEAN_PATH are cleared. The opt-in extcheck
shell provides Rust and an explicit elan path without Lean/Lake proxy shims on PATH.
CI keys the tools cache on both flake files as well as pins, builder and toolchain.
The required root regression gate runs the production driver with local sources and executable stubs, checking cache reuse,
cache corruption, pin mismatches, ambient Lake isolation, cleared overrides and
elan-home isolation. It checks the actual extcheck PATH and rejects a simulated proxy leak.
