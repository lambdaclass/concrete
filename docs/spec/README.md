# The Concrete Language Specification

This directory is the one written statement of the Concrete language: what a program means, which
programs are refused, and why. Every rule has a stable, versioned ID and runnable examples, and is
checked against the compiler and the interpreter on every push.

- Start with the [overview](overview.md): what Concrete is, how to read a rule, and the chapter map.
- Read it as one document: [SPEC.md](SPEC.md), generated from the chapters.
- The questions only the project owner decides: [decisions.md](decisions.md).
- How the specification is maintained (format, registry, gates, migration): [MAINTAINERS.md](MAINTAINERS.md).
