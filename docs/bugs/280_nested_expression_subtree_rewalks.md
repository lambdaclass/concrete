**Status:** OPEN
**Found:** 2026-10-26, building the compile-time scaling gate (R-0550, exit 2o): the gate's generated shapes, timed per stage with `--emit-trace-json` at 10b81a46.
**Severity:** loud (performance). Compile time only: never wrong code, a refusal or a crash; a program of this shape compiles, slowly.

## Reproducer

Generated by `scripts/tests/lib/compile_scaling.py` (`gen`); per-stage time in ms from `concrete <file> --emit-trace-json` (`timing_ms`), one run each on the dev host at 10b81a46:

- `nested-parens` (`let s: i64 = (1 + (1 + ( ... (1 + 0) ... )));` nested n deep in `main`), `check` stage: 2500: 62 ms, 5000: 256 ms, 10000: 1007 ms, 20000: 3851 ms.
- `nested-parens` (`let s: i64 = (1 + (1 + ( ... (1 + 0) ... )));` nested n deep in `main`), `elaborate` stage: 2500: 10 ms, 5000: 31 ms, 10000: 134 ms, 20000: 605 ms.

A linear stage doubles with the size; these grow about fourfold or more per doubling.

## Cause

`Check/CheckHelpers.lean`, `operandEscape?`/`firstOperandEscape?` (bug 142's exit-in-operand rule) walk an operand's whole subtree and Check asks it at every binary node; `Semantics/TypeJudgment.lean`, `isFlexibleLit` recurses through the whole literal-only binop tree and both `checkExpr` and `elabExprEv` ask it at every level (gdb samples: `firstOperandEscape?` under `checkExpr`, `isFlexibleLit` under `elabExprEv`).

## Expected

Compute both facts bottom-up once per node (returned with the node's result, or cached), so each node is visited a bounded number of times.

## Containment while open

Loud only. The scaling gate names the stage as an exclusion under this bug, so its gap is printed on every run rather than silent; the gate's other stages of the shape stay judged. A user splits such a module or nest.

## Structural cause

Class 17 ("pass state in association lists and per-query recomputation"): a program-wide or nesting-wide question answered by a walk of a list (or a subtree) per item, the shape of bugs 027, 249 and 255 - 261.

## Structural owner

R-0422; the one TypeJudgment (Phase 6.5) owns `isFlexibleLit`. The R-0550 gate (exit 2o) keeps the class from returning once fixed.
