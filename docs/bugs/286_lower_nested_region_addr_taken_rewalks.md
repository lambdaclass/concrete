**Status:** FIXED (branch `wip/perf-286`, based on `wip/bug-285`)
**Found:** 2026-10-26, attributing the `nested-ifs` exclusion of the R-0550 scaling gate
(`compile_scaling_budgets.tsv`: "lower: still superlinear ... not yet attributed").
**Severity:** loud (performance). Compile time only: the emitted IR is unchanged.

## Reproducer

`nested-ifs` of `scripts/tests/lib/compile_scaling.py` (`if t > 0 { s = s + 1; if t > 0 { ... } }`
nested n deep in `main`), `lower` stage of `--emit-trace-json`, dev host (fede-256gb), main
cc7a4084, fastest of 3:

| depth | 1000 | 2000 | 4000 | 8000 | 10000 |
|---|---|---|---|---|---|
| `lower`, ms | 23 | 78 | 296 | 1275 | 1771 |
| `lower`, heartbeats | 604607 | 1208612 | 2416606 | 4832609 | 6040613 |

Time grows fourfold per doubling while allocations double: a walk that allocates nothing. Callgrind
(exclusive instructions) at depth 4000: `cexprAddrTaken` 1456 M, `cstmtAddrTaken` 728 M and the
`cstmtsAddrTaken` fold 664 M of 4546 M; at depth 2000, 712 M of 1653 M.

## Cause

`IR/Lower.lean`: bug 031's pre-promotion (`prePromoteAddrTaken`) at the statement `if`, the value
`if`, `match` and the short-circuit right operand, and the loop's slot-or-phi choice at `while`,
each ask for the set of locals their region takes the address of, computed by a fresh walk of the
region (`cstmtsAddrTaken` / `cmatchArmAddrTaken` / `cexprAddrTaken`, one walk since bug 263). The
region of a site at depth d contains the n - d levels below it, so the walks total n²/2 nodes.
Codex review 2026-10-26 found no other per-level subtree walk in Lower, SSAVerify or SSACleanup
for this shape.

## Fix

A region's set is a superset of every nested region's (its source contains theirs), and a site
acts only on the bindings in scope before it that pass the test it applies before promoting (not
promoted, not an array, not rebound by an arm; for a loop, not promoted and not an aggregate).
`LowerState.addrBound` holds the set of the enclosing region while its source is lowered
(`withAddrBound`); a site (`regionAddrTaken`) first asks whether any binding in scope in that set
passes its test. If none does, no binding of its exact set does either, and the bound stands in
for the walked set, so the site does exactly what it did. Otherwise it walks its region as before.
The bound is cleared while deferred calls are lowered, since their source is not in the region
they are emitted in. In the nest, each site finds nothing in the empty bound and no level is walked
twice.

The emitted IR is unchanged: `--emit-ssa` and `--emit-llvm` of every `.con` under
`tests/programs` and `examples` (4126 compiles) and of 3000 programs generated by
`scripts/tests/fuzz_differential.py`'s generator (depth 4, every one taking an address) are
byte-identical with the compiler of `wip/bug-285`.

## Measurements

`lower` stage, ms, fastest of 3, dev host, before (main cc7a4084) and after:

| depth | before | after |
|---|---|---|
| 1000 | 23 | 13 |
| 10000 | 1771 | 154 |
| 100000 | not finished in 30 min | 5000 |

Callgrind instruction counts with the fix grow exactly twofold from depth 8000 to 16000 in every
stage (lower 1755 M to 3512 M). The wall time still grows faster than the instruction count at
10^5 (x32 from 10^4), which is the memory hierarchy, not work: allocations grow exactly tenfold.
The same sites made nested `if`/`else`, nested `match` and nested blocks quadratic in Lower: at
depth 8000 their `lower` stage goes from 2029, 2577 and 1835 ms to 325, 510 and 377 ms.

## Regression gate and leg

The scaling gate's `nested-ifs` shape is no longer excluded (`compile_scaling_budgets.tsv`).
`run_tests.sh` times the `lower` stage of a generated nest 8000 deep against 400 ms, retried once
at 800 ms (118 ms with the fix; 1275 ms before). `regress_286_nested_region_addr_taken.con` pins
the cases where the bound must not stand in for the walk (a local declared inside the outer region
and addressed in a nested one, a local addressed after the nest, a loop inside a branch); binary =
`--interp` = 42.

## Structural cause

Class 17 ("pass state in association lists and per-query recomputation"): a nesting-wide question
answered by a walk of the subtree per level, the shape of bugs 178, 280 and 281.

## Structural owner

R-0501 (S10 Place MIR): the storage of every local decided once per function, which removes the
per-site walks; R-0422 holds the throughput envelope meanwhile.
