**Status:** OPEN
**Found:** 2026-10-26, building the compile-time scaling gate (R-0550, exit 2o): the gate's generated shapes, timed per stage with `--emit-trace-json` at 10b81a46.
**Severity:** loud (performance). Compile time only: never wrong code, a refusal or a crash; a program of this shape compiles, slowly.

## Reproducer

Generated by `scripts/tests/lib/compile_scaling.py` (`gen`); per-stage time in ms from `concrete <file> --emit-trace-json` (`timing_ms`), one run each on the dev host at 10b81a46:

- `functions` (`fn f<i>(x: i64) -> i64 { return x + <i % 3>; }` for i < n, and a `main` that calls `f0` and `f<n-1>`), `lower` stage: 2500: 17 ms, 5000: 70 ms, 10000: 279 ms, 20000: 1451 ms.
- `call-chain` (`fn f<i>(x: i64) -> i64 { return f<i+1>(x) + 1; }` for i < n, `fn f<n>(x: i64) -> i64 { return x; }`, and a `main` that calls `f0`), `lower` stage: 2500: 28 ms, 5000: 136 ms, 10000: 589 ms, 20000: 4069 ms.
- `structs` (`struct S<i> { a: i64, b: i64 }` for i < n, and a `main` that builds and destructures `S<n-1>`), `lower` stage: 2500: 8 ms, 5000: 56 ms, 10000: 297 ms, 20000: 1380 ms.
- `enums` (`enum E<i> { A { v: i64 }, B }` for i < n, and a `main` that matches `E<n-1>::A`), `lower` stage: 2500: 7 ms, 5000: 40 ms, 10000: 281 ms, 20000: 1169 ms.

A linear stage doubles with the size; these grow about fourfold or more per doubling.

## Cause

`IR/Lower.lean`, `lowerModule`: the per-function fold appends `acc ++ [(sfn, lits)]`; the external structs, enums and newtypes are filtered with `ownStructs.any`/`ownEnums.any` per type and deduplicated with `acc.any` then `acc ++ [sd]`; `lowerExpr` asks `st.definedFns.contains` per call (the last two found by the Codex review). gdb samples: `lowerModule`'s fold.

## Expected

Accumulate in an `Array`; key the own and external type names and the defined functions by a set.

## Containment while open

Loud only. The scaling gate names the stage as an exclusion under this bug, so its gap is printed on every run rather than silent; the gate's other stages of the shape stay judged. A user splits such a module or nest.

## Structural cause

Class 17 ("pass state in association lists and per-query recomputation"): a program-wide or nesting-wide question answered by a walk of a list (or a subtree) per item, the shape of bugs 027, 249 and 255 - 261.

## Structural owner

R-0422; ROADMAP #5 (the Lower builder). Lower's per-function quadratics are bugs 265-267 (fixed) and 270. The R-0550 gate (exit 2o) keeps the class from returning once fixed.

Codex review 2026-10-26: CONFIRMED — `lowerModule`'s function-result append is quadratic; for single-module types the cause is the per-type `ownStructs.any`/`ownEnums.any` filters; additionally `lowerExpr` scans `definedFns` per call.
