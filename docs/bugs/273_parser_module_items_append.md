# Bug 273 — the parser appends each struct, enum, constant, newtype, import and submodule of a module to the list built so far (quadratic in declarations)

**Status:** OPEN
**Found:** 2026-10-26, building the compile-time scaling gate (R-0550, exit 2o): the gate's generated shapes, timed per stage with `--emit-trace-json` at 10b81a46.
**Severity:** loud (performance). Compile time only: never wrong code, a refusal or a crash; a program of this shape compiles, slowly.

## Reproducer

Generated by `scripts/tests/lib/compile_scaling.py` (`gen`); per-stage time in ms from `concrete <file> --emit-trace-json` (`timing_ms`), one run each on the dev host at 10b81a46:

- `structs` (`struct S<i> { a: i64, b: i64 }` for i < n, and a `main` that builds and destructures `S<n-1>`), `parse` stage: 2500: 34 ms, 5000: 145 ms, 10000: 684 ms, 20000: 3005 ms.
- `enums` (`enum E<i> { A { v: i64 }, B }` for i < n, and a `main` that matches `E<n-1>::A`), `parse` stage: 2500: 35 ms, 5000: 154 ms, 10000: 714 ms, 20000: 3223 ms.

A linear stage doubles with the size; these grow about fourfold or more per doubling.

## Cause

`Frontend/Parser.lean`, `parseModuleBody`: every declaration kind except functions is accumulated with `xs := xs ++ [item]` (structs, unions, enums, constants, newtypes, imports, submodules), copying the list built so far; functions are consed and reversed once, which is why a module of many functions parses in linear time.

## Expected

Accumulate in an `Array` (or cons and reverse once), as `fns` already does and as bugs 249 and 255 did for array literals and block statements.

## Containment while open

Loud only. The scaling gate names the stage as an exclusion under this bug, so its gap is printed on every run rather than silent; the gate's other stages of the shape stay judged. A user splits such a module or nest.

## Structural cause

Class 17 ("pass state in association lists and per-query recomputation"): a program-wide or nesting-wide question answered by a walk of a list (or a subtree) per item, the shape of bugs 027, 249 and 255 - 261.

## Structural owner

R-0422 (compiler throughput queue, complexity envelopes); the parser's append ratchet (`check_no_quadratic_append.sh`) counts this shape but predates it. The R-0550 gate (exit 2o) keeps the class from returning once fixed.

Codex review 2026-10-26: CONFIRMED — `parseModuleBody` repeatedly copies the growing struct/enum lists with `++ [item]`; the cited site is correct and quadratic.
