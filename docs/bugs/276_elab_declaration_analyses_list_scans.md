**Status:** OPEN
**Found:** 2026-10-26, building the compile-time scaling gate (R-0550, exit 2o): the gate's generated shapes, timed per stage with `--emit-trace-json` at 10b81a46.
**Severity:** loud (performance). Compile time only: never wrong code, a refusal or a crash; a program of this shape compiles, slowly.

## Reproducer

Generated by `scripts/tests/lib/compile_scaling.py` (`gen`); per-stage time in ms from `concrete <file> --emit-trace-json` (`timing_ms`), one run each on the dev host at 10b81a46:

- `functions` (`fn f<i>(x: i64) -> i64 { return x + <i % 3>; }` for i < n, and a `main` that calls `f0` and `f<n-1>`), `elaborate` stage: 2500: 131 ms, 5000: 667 ms, 10000: 3689 ms, 20000: 40745 ms.
- `call-chain` (`fn f<i>(x: i64) -> i64 { return f<i+1>(x) + 1; }` for i < n, `fn f<n>(x: i64) -> i64 { return x; }`, and a `main` that calls `f0`), `elaborate` stage: 2500: 165 ms, 5000: 886 ms, 10000: 6612 ms, 20000: 29555 ms.
- `structs` (`struct S<i> { a: i64, b: i64 }` for i < n, and a `main` that builds and destructures `S<n-1>`), `elaborate` stage: 2500: 79 ms, 5000: 416 ms, 10000: 2146 ms, 20000: 8355 ms.
- `enums` (`enum E<i> { A { v: i64 }, B }` for i < n, and a `main` that matches `E<n-1>::A`), `elaborate` stage: 2500: 79 ms, 5000: 415 ms, 10000: 2472 ms, 20000: 10406 ms.

A linear stage doubles with the size; these grow about fourfold or more per doubling.

## Cause

`Elab/Elab.lean`: `qualifyCollidingTopLevelFns` recomputes a module's free-function list for every owner (`(freeFns mn).contains n`) and asks `owners.any` per owner; `coreDefinitionSpellings` (through `importSpellingCollisions`) and `ambiguousTypeNames` deduplicate with `List.eraseDups` and count each name with `decls.filter (·.1 == n)`; `elabModule`'s per-function fold appends each result (`acc ++ [...]`); `lookupFn` walks `env.fnSigs` per call (the Codex review). gdb samples: `qualifyCollidingTopLevelFns`/`coreDefinitionSpellings` dominate for many functions, `ambiguousTypeNames` and the `elabModule` folds for many structs and enums.

## Expected

Each analysis keys a map or set by name once per program; results accumulate in an `Array`.

## Containment while open

Loud only. The scaling gate names the stage as an exclusion under this bug, so its gap is printed on every run rather than silent; the gate's other stages of the shape stay judged. A user splits such a module or nest.

## Structural cause

Class 17 ("pass state in association lists and per-query recomputation"): a program-wide or nesting-wide question answered by a walk of a list (or a subtree) per item, the shape of bugs 027, 249 and 255 - 261.

## Structural owner

R-0422; R-0492 (identities) owns the collision analyses' inputs. The R-0550 gate (exit 2o) keeps the class from returning once fixed.

Codex review 2026-10-26: CONFIRMED — the cited recomputation, list membership scans, `eraseDups`, per-name filtering and result appending are quadratic; additionally `Elab.lookupFn` scans `env.fnSigs` per call.
