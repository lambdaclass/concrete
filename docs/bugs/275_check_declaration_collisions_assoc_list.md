**Status:** OPEN
**Found:** 2026-10-26, building the compile-time scaling gate (R-0550, exit 2o): the gate's generated shapes, timed per stage with `--emit-trace-json` at 10b81a46.
**Severity:** loud (performance). Compile time only: never wrong code, a refusal or a crash; a program of this shape compiles, slowly.

## Reproducer

Generated by `scripts/tests/lib/compile_scaling.py` (`gen`); per-stage time in ms from `concrete <file> --emit-trace-json` (`timing_ms`), one run each on the dev host at 10b81a46:

- `functions` (`fn f<i>(x: i64) -> i64 { return x + <i % 3>; }` for i < n, and a `main` that calls `f0` and `f<n-1>`), `check` stage: 2500: 12 ms, 5000: 42 ms, 10000: 159 ms, 20000: 635 ms.
- `call-chain` (`fn f<i>(x: i64) -> i64 { return f<i+1>(x) + 1; }` for i < n, `fn f<n>(x: i64) -> i64 { return x; }`, and a `main` that calls `f0`), `check` stage: 2500: 26 ms, 5000: 98 ms, 10000: 432 ms, 20000: 1546 ms.
- `structs` (`struct S<i> { a: i64, b: i64 }` for i < n, and a `main` that builds and destructures `S<n-1>`), `check` stage: 2500: 9 ms, 5000: 31 ms, 10000: 260 ms, 20000: 1202 ms.
- `enums` (`enum E<i> { A { v: i64 }, B }` for i < n, and a `main` that matches `E<n-1>::A`), `check` stage: 2500: 9 ms, 5000: 43 ms, 10000: 316 ms, 20000: 1499 ms.

A linear stage doubles with the size; these grow about fourfold or more per doubling.

## Cause

`Check/Check.lean`, `declarationCollisions`: `seen` is a `List (String × (String × Span))` and every declaration asks `seen.lookup n` (gdb samples: `List.lookup` under `declarationCollisions`). For calls (the call-chain shape), `CheckHelpers.lookupFn` finds the callee with `listGetIdx env.functions`, a walk of the module's function list per call (found by the Codex review).

## Expected

A hash set (or map) of the names seen, and the function table keyed by name.

## Containment while open

Loud only. The scaling gate names the stage as an exclusion under this bug, so its gap is printed on every run rather than silent; the gate's other stages of the shape stay judged. A user splits such a module or nest.

## Structural cause

Class 17 ("pass state in association lists and per-query recomputation"): a program-wide or nesting-wide question answered by a walk of a list (or a subtree) per item, the shape of bugs 027, 249 and 255 - 261.

## Structural owner

R-0422; R-0499/R-0514 (row 4) own the checker's environments. The R-0550 gate (exit 2o) keeps the class from returning once fixed.

Codex review 2026-10-26: CONFIRMED — `declarationCollisions` searches the growing `seen` association list for every declaration; additionally `CheckHelpers.lookupFn` walks `env.functions` per call.
