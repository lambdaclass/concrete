# Bug 278 — Mono finds colliding type names by filtering the whole name list per name (quadratic in types)

**Status:** OPEN
**Found:** 2026-10-26, building the compile-time scaling gate (R-0550, exit 2o): the gate's generated shapes, timed per stage with `--emit-trace-json` at 10b81a46.
**Severity:** loud (performance). Compile time only: never wrong code, a refusal or a crash; a program of this shape compiles, slowly.

## Reproducer

Generated by `scripts/tests/lib/compile_scaling.py` (`gen`); per-stage time in ms from `concrete <file> --emit-trace-json` (`timing_ms`), one run each on the dev host at 10b81a46:

- `structs` (`struct S<i> { a: i64, b: i64 }` for i < n, and a `main` that builds and destructures `S<n-1>`), `monomorphize` stage: 2500: 18 ms, 5000: 114 ms, 10000: 688 ms, 20000: 2490 ms.
- `enums` (`enum E<i> { A { v: i64 }, B }` for i < n, and a `main` that matches `E<n-1>::A`), `monomorphize` stage: 2500: 18 ms, 5000: 87 ms, 10000: 702 ms, 20000: 2455 ms.

A linear stage doubles with the size; these grow about fourfold or more per doubling.

## Cause

`IR/Mono.lean`, `monoProgram`: `ownNames.filter fun n => (ownNames.filter (· == n)).length > 1` and `eraseDups` (gdb samples under `monoProgram`). Also observed, not localized and not part of this record: the many-functions shape's `monomorphize` stage grows faster than linearly in time (5000: 6 ms, 20000: 168 ms at 10b81a46) with linear allocation counts; the gate holds it by its budget (it stays under the growth check's 100 ms resolution at the gate's sizes).

## Expected

Count names in one pass over a map.

## Containment while open

Loud only. The scaling gate names the stage as an exclusion under this bug, so its gap is printed on every run rather than silent; the gate's other stages of the shape stay judged. A user splits such a module or nest.

## Structural cause

Class 17 ("pass state in association lists and per-query recomputation"): a program-wide or nesting-wide question answered by a walk of a list (or a subtree) per item, the shape of bugs 027, 249 and 255 - 261.

## Structural owner

R-0422; R-0492 owns type identities (a respelled type is the collision's real subject). The R-0550 gate (exit 2o) keeps the class from returning once fixed.

Codex review 2026-10-26: PARTLY CONFIRMED — `monoProgram`'s nested `ownNames.filter` is the correct quadratic cause for many structs and enums; the many-functions timing growth was not localized (recorded above as an observation, outside this bug).
