1. **major — ConcreteSpec/Spec/Exec.lean:78–89, 178–181, 296–305.** The execution interface cannot carry shared mutable state across calls. `Config` contains only locals and frames; operand evaluation sees only locals; primitives return a value without an updated store. A callee receives only its parameters, and returning restores the saved caller locals. Consequently, a function or destructor cannot modify storage that a later caller read observes. C4’s hybrid memory and C5’s loans cannot be supplied merely as operand instances, as the module header promises. **Fix:** parameterize configurations and primitive transitions by shared machine state, thread it through calls and cleanup, and let operand reads consult it. Prove that calls restore caller bindings while preserving shared-state effects.

2. **major — ConcreteSpec/Spec/Scalar.lean:239–245.** Machine contract terms accept operands outside the selected machine type’s domain. For example, machine `u8` subtraction of literal `256` from literal `256` evaluates to `some 0`; machine `u8` right shift of `256` by zero evaluates to `some 256`. Neither denotes a runtime operation on `u8` values. The range-preservation theorem assumes valid inputs, but `CTerm.eval` neither enforces that premise nor has a typing judgment supplying it. **Fix:** require representable operands before evaluating machine terms, with the appropriate separate shift-count rule, or introduce typed contract terms and prove their operand-validity and runtime-correspondence laws.

3. **major — ConcreteSpec/Spec/Const.lean:15, 183–203, 251–255.** The subset turns *source declaration order* into an admission restriction: an acyclic reference to a later constant is refused. Item 26 authorizes defining a closed total subset, but the supplied decisions do not establish this particular source-order restriction. Totality requires well-founded dependencies, which does not itself require textual ordering. This is an additional language choice presented as decided behavior. **Fix:** distinguish dependency order in Core from source order, allowing elaboration to topologically order acyclic declarations; alternatively, obtain an explicit owner decision before specifying forward references as refused.

4. **major — ConcreteSpec/Spec/Scalar.lean:55–59, 92–105.** C2’s scalar representation interface covers integers only. The proposal explicitly requires booleans to encode as byte `0` or `1`, but this slice provides neither boolean encoding/partial decoding nor correspondence laws. `CVal.bool` establishes two mathematical values, without constraining their byte representation. This leaves a required C2 law absent precisely where C4 will need scalar validity. **Fix:** add boolean encoding and partial decoding, prove round-trip and successful-decoding validity, and show that other byte values are refused. The separately approved removal of `char` should remain respected.

5. **minor — ConcreteSpec/Proofs/Exec.lean:173–180.** The comment says an exit runs “exactly” the cleanup plan, but `unwind_runs_plan` proves existence of one execution with that trace. With nondeterministic primitive answers, `Completes` supplies a successful path without excluding another path that traps or diverges. The theorem is meaningful and its premises have a witness, but it does not establish the stated universal characterization. **Fix:** describe it as a conditional successful-execution theorem, and add an execution-inversion or prefix theorem showing that every execution follows the cleanup order until completion, trapping, or divergence.

6. **minor — ConcreteSpec/Spec/Const.lean:202–203; ConcreteSpec/Proofs/Const.lean:44.** Expression totality is proved from `ty?` and `Agree`, whereas declaration admission uses `evalConsts` directly. No theorem connects admitted declarations to those typing premises or proves that evaluation from the empty environment produces only valid, correctly typed bindings. Thus the expression theorem does not yet justify the registered declaration rule’s full description. **Fix:** prove declaration-level soundness and completeness against a sequential typing judgment, including environment agreement and validity preservation.
