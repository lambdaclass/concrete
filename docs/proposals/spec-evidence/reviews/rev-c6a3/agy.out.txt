### Overview

Round 3 addresses the Round 2 findings only partially and introduces new shortcuts and convention defects:

1. **Physical output independence (`PhysicalEffects`, `project_physical_outputs`, `output_before_trap_kept`)**: `PhysicalEffects` is passed as an unconstrained parameter (`F : PhysicalEffects O S.Output`) rather than fixed by the operand/signature semantics, so an erasing adapter still satisfies both `OutputCorrespondence A F.past` and `F.OracleFaithful ρ` under the trivial zero-effect instance (`F.emit := []`, `F.past := []`). Furthermore, `PhysicalEffects.Execution.refl` has no termination/blocking guard, so `F.Execution` can stop early at any intermediate configuration after the last event-emitting step, and `finalConfig` in `project_physical_outputs` / `output_before_trap_kept` is unconstrained.
2. **Typed environment execution in C1 (`environment_run_reply`)**: Instead of connecting `Environment` to general C1 operands or `reportObservation`, the patch defines a synthetic toy operand instance `Environment.operands S` (with `Store := Unit`) and a single-instruction configuration `Environment.call` whose destination variable is `none : Option Var`. Because `dst = none`, `Exec.onRes` discards the C1 return value `.ok (some ⟨q.1, reply⟩)` and leaves locals empty; a mutant oracle returning `.ok none` as its C1 value while logging the event still satisfies `environment_run_reply`. Blocking (`E.reply = none`) is also switched off by the `answered` premise (`= some reply`) rather than covered operationally.
3. **Source-to-trap pipeline (`SourcePosition`, `sourceSites`, `runFrom_source_trap`)**: `SourcePosition` still bundles `pathOk : PathOk path` as a premise field, and the second conjunct of `runFrom_source_trap` (`(sourcePrefixSpan src.path src.pathOk src.prefixText).PathOk`) is proved literally by `exact src.pathOk` (a premise projection). Worse, the conclusion of `runFrom_source_trap` hardcodes `sourcePrefixSpan src.path src.pathOk src.prefixText` verbatim on the RHS instead of specifying the target span properties (`sp.path = src.path`, 1-based line, byte column), so `runFrom_source_trap` merely unfolds `sourceSites = AList.map (sourcePrefixSpan ...)` on a lookup.

     1. `PhysicalEffects.Execution.refl` (`Spec/Observe.lean:421`) is unguarded: `F.Execution P ρ hist c [] hist c` holds for any configuration `c`, even when `c` can still step.
