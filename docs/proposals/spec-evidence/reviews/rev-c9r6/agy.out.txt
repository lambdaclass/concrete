1. **`ConcreteSpec/Proofs/Ident.lean:859-883` and `ConcreteSpec/Proofs/Ident.lean:1559-1606` — MAJOR — `REAL DEFECT`**
   - **Problem**: [`LoadedModules.load_refusal_sound`](file:///home/unbalancedparen/ConcreteSpec/Proofs/Ident.lean#L861-L868) and [`LoadedModules.load_admitted`](file:///home/unbalancedparen/ConcreteSpec/Proofs/Ident.lean#L872-L883) were rewritten as `match load modules with | .refused collision => HasCollision modules collision | .admitted _ => True` and `match load modules with | .admitted admitted => admitted = modules ∧ WellFormed modules | .refused _ => True`.
     - Any mutant returning `.admitted _` (such as `admitAll` or `discardLoad`) satisfies `load_refusal_sound` vacuously via `True`.
     - Any mutant returning `.refused _` (such as `fabricatedRefusalLoad`) satisfies `load_admitted` vacuously via `True`.
     - Worse, on any collision-free input such as the `Instance` `[firstModule, secondModule]`, `WellFormed [firstModule, secondModule]` is **already true of the input**, so the mutant `admitAll` (which never checks for package/module collisions!) **passes** `load_admitted [firstModule, secondModule]`. To work around this, the diff replaced `admitAll [firstModule, collidingModule]` with `discardLoad [firstModule, secondModule]` (`_ := .admitted []`) at line 1598, whose proof (`cases h.1`) only refutes `[] = [firstModule, secondModule]` and never tests `WellFormed modules` at all (`admitAll` is left dead code).
   - **Concrete long-term fix**:
     - State the total output contract on `load modules` without a `True` branch (or state `load_admitted` as the biconditional `load modules = .admitted admitted ↔ admitted = modules ∧ WellFormed modules`, and keep `match load modules with | .admitted admitted => admitted = modules ∧ WellFormed modules | .refused collision => HasCollision modules collision` for total output soundness).
     - Test `admitAll` on `[firstModule, collidingModule]` (or `[firstModule, samePackageOtherOrigin]`) as a `Planted` witness so collision refusal (`WellFormed`) is actually falsified by a mutant.

   - **Concrete long-term fix**:
