### Round-2 Fix Verification

The Round-2 defect is genuinely fixed:
1. **`ReportedQueries` (`ConcreteSpec/Spec/Adequacy.lean:147-177`)** is now parameterized by `(P : Program O) (ρ : QueryOracle O)` and indexed over `Conclusion P ρ ending pos`.
2. **Authenticated terminal queries**: The request-stopping constructors (`stuckContinuation`, `noAnswer`, `badAnswer`) require `hs : step P c = some (.request p vs site st k)` together with the corresponding oracle/allowance/continuation equations (`ha`, `hallow`, `hk`), and append `Query.issue events p vs site st issued` rather than an unconstrained `{q}`. Because `step P c` is deterministic, `p`, `vs`, `site`, and `st`—and therefore the appended `Query.issue`—are uniquely determined by `c`, `events`, and `issued`.
3. **Disjoint stuck histories**: `ReportedQueries.stuck` requires `hs : step P c = none` (appending nothing), whereas `ReportedQueries.stuckContinuation` requires `hs : step P c = some (.request ...)` (appending the issued query). Because `step P c` cannot be both `none` and `some (.request ...)`, machine-stuck and continuation-refused `.stuck c` endings cannot swap query histories even if `Conclusion` is proof-irrelevant.
4. **`runFromQ_sound` (`ConcreteSpec/Proofs/Adequacy.lean:242-322`)** now returns `∃ n pos, Moves P ρ n ⟨c, events, issued⟩ pos ∧ (runFromQ P ρ fuel events issued c).events = pos.events ∧ ∃ hc : Conclusion P ρ (runFromQ P ρ fuel events issued c).ending pos, ReportedQueries P ρ hc (runFromQ P ρ fuel events issued c).queries`.
