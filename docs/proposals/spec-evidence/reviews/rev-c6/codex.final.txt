1. **ConcreteSpec/Spec/Observe.lean:229 — major — REAL DEFECT.** `ExecAdapter` does not establish C1’s request/response split. `events` can erase every event or fabricate unmatched responses, with no law relating it to `request`, C1’s accepted answers, or `ValidTrace`. An accepted answer with `event = none` cannot contribute its external request through this projection. Consequently, `output_before_trap_kept` also holds for an adapter that discards all output. **Fix:** provide a lawful adapter relating primitive transitions and answers to typed request/response events, and prove trace validity and output preservation for it. Project transitions rather than only answer events where the latter lack the necessary information.

2. **ConcreteSpec/Spec/Observe.lean:262 — major — REAL DEFECT.** Every typed `noAnswer` becomes an externally blocked behavior without checking `OperationContract.mayBlock`. Thus an operation that explicitly forbids blocking can still yield `.blocked`. The pending request is also absent from the event list, although `ValidTrace` represents a pending request by a history containing its request event. **Fix:** distinguish an unanswered evaluator query from an admissible maximal blocked behavior; require the environment’s blocking evidence and include the pending request exactly once in the canonical history. Update `report_noAnswer_blocked` accordingly.

3. **ConcreteSpec/Spec/Observe.lean:95 — major — REAL DEFECT.** The response contract need not receive the documented history “ending in that request.” `ValidTrace.output` permits output while a request is outstanding, so `[request q, output o, response r]` checks `allows` against `[request q, output o]`. Contracts inspecting the last event therefore behave differently from the stated interface. **Fix:** either restrict output to idle states, or retain the history at request issuance separately and pass that snapshot to `allows`. Document the chosen sequential semantics consistently.

4. **ConcreteSpec/Spec/Observe.lean:159 — major — REAL DEFECT.** Full observations cannot independently record externally visible final state, which C6 explicitly requires preserving. `Observation` contains only events and a terminal action; `Execution` and `SameObservation` likewise omit final external state. Two runs with identical events and exit status but different externally visible final states are therefore indistinguishable. **Fix:** add an abstract external-state observation and its adapter projection, or define and prove how the history determines it. Include it in full-observation preservation.

5. **ConcreteSpec/Spec/Observe.lean:140 — minor — REAL DEFECT.** A trapped terminal stores an unrestricted diagnostic string independently of its kind, site and span. For example, a terminal with line `"anything"` is admitted, and `trapLine_injective` says nothing about it. No well-formedness predicate excludes such observations. **Fix:** derive the line from the stored triple, or require a rendering-equality invariant wherever terminal observations are admitted.
