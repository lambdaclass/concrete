   - **Concrete fix:** Include block metadata preservation in `Footprint.Preserves` for blocks not touched by `f` (or define `Footprint.BlockOutside (f : Footprint) (b : MemBlockId) : Prop := ∀ r ∈ f.bytes, r.block ≠ b ∨ r.extent = 0`, and require in `Footprint.Preserves` both byte preservation at `f.ByteOutside b i` and full block metadata preservation `y.live = x.live ∧ y.exposed = x.exposed ∧ y.space = x.space ∧ y.base = x.base ∧ y.size = x.size ∧ y.align = x.align` whenever `f.BlockOutside b`).
