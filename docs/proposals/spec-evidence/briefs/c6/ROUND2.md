An evaluator that fails to supply an answer is not a program that blocks. Add the blocking-permission premise (or classify a noAnswer for a request whose contract forbids blocking as no observation / an evaluator report, never as blocking), and state the law accordingly.

Prove the real stuttering law: inserting any finite number of silent steps anywhere in a finite run, and stuttering an infinite run (via a strictly increasing index map, with all other steps silent), preserves the observation. An infinite run whose steps are all silent after some point must never be related to a terminated run.
