Found guard-derived laws and one cleanup claim that is weaker than its advertised meaning. The memory and hybrid invariant-preservation proofs do **not** recheck the whole invariant at runtime.

This is a source audit only: no files changed, git writes, network access, or builds. C6 statements were audited despite the acknowledged partial-continuation mismatch.

Here, a concrete computation equation can be NON-VACUOUS even when proved by `rfl`: changing its implementation can falsify its specified result. VACUOUS identifies laws whose claimed property is already an assumed field, a successful guard, or generic functional congruence. Anonymous examples serve as witnesses; the registered rule is inventoried separately.

Notation: **N** = NON-VACUOUS; **V** = VACUOUS; **W** = WEAK. “Mutation” means a hypothetical source change, not an executed test.
