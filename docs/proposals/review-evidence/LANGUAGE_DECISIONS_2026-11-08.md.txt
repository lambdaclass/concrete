B. Language simplifications
6. Remove dot method calls; Type::f(x) or Trait::f(x). Yes.
7.* Replace self/&self/&mut self receiver forms with an ordinary typed first parameter, preserving one consuming Destroy protocol. Yes.
8. Constructors always field: value. Yes.
9. Patterns always field: binder (revises OD130; ignored-field rules and linear consumption preserved). Yes.
10. Contracts mark exact mathematical arithmetic explicitly (spelling/scope later; OD12, OD145 preserved). Yes.
11. Remove `as` from the language entirely (owner 2026-11-08: fully gone, not reserved). (a) expression casts replaced by one canonical named lossless conversion (OD11 value-domain rule and provenance restrictions preserved); (b) import renaming removed; imported items are ALWAYS used qualified by their module's last segment (owner 2026-11-08: "i like 3"): `import std::json::{parse};` then `json::parse(...)`, `vec::Vec<u8>`, never bare; same-module items and builtin types stay bare; two same-named items from different modules may both be imported (revises MOD-3); two imported modules with the same last segment are refused; a local named like an imported segment is refused (no shadowing); MOD-2 manifest and OD139 kept; (c) borrow revises Core Q4.7/Q9.5: `borrow [mut] view = source [from a until b] { ... } [else { ... }]`; (d) unpack: `unpack <brand A> x = p { ... }`. Spellings illustrative; exact ones in the spelling round.
12. Replace consuming *h on heap boxes with one named move-out (allocator identity, conservation, distinct from destruction). Yes.
13. assert(e); always parenthesized (optional `by` suffix). Yes.
14. #[link_name("sym")] / #[export_name("sym")]. Yes.
15. Imports use ::. Yes.
16. Remove char; u8 plus explicit UTF-8 operations; quoted ASCII literals, patterns, comparisons migrate explicitly. Yes.
17.* Remove print/println/append builtins. Output: ordinary calls needing Console and its grant, linear errors kept. String append: ordinary allocating operation under with(Alloc), not Console. Yes.
18. Every local has a written type and every function a result arrow incl. -> Unit; argument-based generic inference kept; destructuring/ghost-binding typing rules defined later (item 55). Yes.

C. Removals and keeps
19. OrderedMap only now; HashMap when the KV store (slice 23) measures need; no compiler privilege for map names. Yes.
20.* Process: audit every foreign declaration first; remove only if none needs it. Yes.
21. defer keeps late reads (Q9.8), with reserved by-value arguments, held loans and cleanup order preserved. Keep.
22.* Refuse handwritten ordinary bodyless functions; compiler-generated interfaces (OD9/OD39) keep bodyless declarations, as do trait signatures and extern. Yes.
23. Remove general packed structs until a real packed foreign ABI needs them (revises OD111/OD147; a demonstrated ABI reopens). Yes.
24.* Local assume: remove only after a replacement (named trusted contracts with evidence identity) is shown on real examples, including point-local conditional facts; until then it stays explicit, tracked and never admits a safety obligation. Yes.
25. Function values: keep decided fn pointer + explicit context with contracts. Keep.
26.* Constants: direction = computed at compile time; constant values must be Copy; the closed total initializer subset is defined, and the decided comptime reopening conditions checked, before revising Q6.4/TYPE-22. Yes.
27.* Explicitly keep value-producing if/match, both proof scopes, existential brands. Keep.
28.* SPARK 4(b): optional #[depends(result <- a, b)], checked against the derived fact, never trusted. Yes.
29.* SPARK 4(c): refuse a dead store to a mut local (extends OD62). Yes.
