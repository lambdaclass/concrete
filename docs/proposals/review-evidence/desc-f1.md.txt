CHANGE: branch wip/stack-tls-reach (written by Kimi), fixing ISS-0028 (Codex-confirmed): the slice-0 stack-bound analysis scripts/checks/lib/stack_bound.py exempted every x86 fs:/gs: absolute operand from stack accounting with any displacement (premise only "the thread-pointer block is not on the stack"); `mov byte ptr fs:[0x100000], 0x0; ret` got bound 0, and the run check scripts/checks/lib/stack_access.py skipped fs/gs operands.
