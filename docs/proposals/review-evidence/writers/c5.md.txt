## Write ConcreteSpec/Spec/Own.lean (+ ConcreteSpec/Proofs/Own.lean); commit each piece separately
1. Ownership state as an instrumentation: owner slots keyed by typed place identity (reuse `Hybrid.Place` or a C9-ready typed identity, explain the choice) with a status (owned / moved), active loans each carrying its original root place and projection path (Q3.3), its mode (shared / mutable) and an optional parent loan (reborrow), loan identities fresh and never reused.
2. Operations on that state, each a partial function (none = refused / stuck, never a repaired state): move out of a slot, reinitialize, take a shared loan, take a mutable loan, reborrow from a loan, end a loan, read and write through an owner or a loan, and the C1 `Life` events (bind, enter, leave, drop). Whole-root conflict (Q3.4): an exclusive loan conflicts with every other active access to the same root, including disjoint projections; a shared loan freezes the whole owner against mutation and move; a reborrow suspends conflicting access through its parent until the child ends.
3. A preservation invariant `Own.WellFormed` (every loan's root is an owned slot; no two conflicting active loans on one root; parent loans exist and are active; children end before parents; a moved slot has no active loan; loan identities below a counter) and prove each operation preserves it.
4. Across calls: entering a callee with loans passed downward (Q3.2, views are downward parameters only) and leaving it preserves the invariant and leaves no loan of the callee's locals active (a loan cannot outlive its root: state and prove it).
5. Erasure: define the projection that forgets the instrumentation and prove that whenever an instrumented operation succeeds, its effect on the concrete store equals the uninstrumented operation's effect (instrumentation never changes a concrete value or branch). Provide an `Operands.life`-compatible function so C1's machine can carry this state, plus one Exec-run example where a use after move is stuck and one where a reborrow ends before its parent is used again.
Give "Accepted"/"Refused" examples for each conflict rule.
