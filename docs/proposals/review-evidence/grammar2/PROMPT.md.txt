Concrete is a systems language rebuilt as a fully proven compiler in Lean. There is no GC; the goal is "know everything" about a program. Ownership is linear: non-Copy values are used exactly once, and Copy is declared and checked, never derived. References are second-class: never returned, with borrow views. Capabilities are explicit grants handed to main. `Secret<T>` gives constant time, and only scalar secrets are Copy. There are no hidden traps: every run-time failure is either proven impossible or explicit (checked_* returning Result<T, ArithmeticError>, abort()). The decided trap line is "concrete: trap: <kind> at <path>:<line>:<col> (site <id>)", with exit 134. Struct layout is declaration order with natural alignment. Backends: an LLVM printer (x86-64, AArch64) and the Lean Compiler Backend (verified, AArch64 first). The Lean spec is the only home of rules. Owner principles: best long-term design; one form per situation, no duplication; LLMs write the code and humans read it, so optimize for checking and reading; work is driven by real workloads; verbose is fine when clear.
